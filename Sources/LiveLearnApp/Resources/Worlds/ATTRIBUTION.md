# Scene material and model credits

## Planet maps

Solar System Scope / INOVE — https://www.solarsystemscope.com/textures/
Licensed under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

Earth, Moon, Mars, Saturn and Saturn ring maps are used on actual native 3D meshes.
Files are renamed for bundling. The Earth daytime 4096px image is the resized version
distributed by the official Three.js example, which credits Solar System Scope:
https://github.com/mrdoob/three.js/blob/master/examples/webgpu_tsl_earth.html

Solar System Scope identifies NASA elevation/imagery and NASA Blue Marble as its underlying
data sources. These artistic maps are not live measurements. The interface's orbital speeds,
distances and relative planet sizes are composed for navigation rather than scientific simulation.

## Landscape models

Kenney — Nature Kit 2.1 and Castle Kit, Creative Commons Zero (CC0).
https://kenney.nl/assets/nature-kit
https://kenney.nl/assets/castle-kit
https://creativecommons.org/publicdomain/zero/1.0/

Selected OBJ models were converted to Collada using Assimp. Tree meshes are subdivided at
render time; materials are adapted to the wilderness palette and cel shading. Included
original license files: Nature/LICENSE.txt and Nature/LICENSE-castle.txt.

Continuous terrain, river, procedural buildings, sky-island assembly, camera, atmospheric
composition, theme controls and animation are implemented in the LiveLearn source.

Earlier generated environment illustrations are concept-only and are not shipped as backgrounds.

Meadow material: generated specifically for this project using OpenAI imagegen on 2026-09-08.
It is a repeating surface material on the 3D terrain, not a scene image. Generation prompt
and original-file provenance are recorded in Assets/Themes/SOURCES.md.
